# open-prd

## Description
Open and summarize the PRD to align changes with project requirements.

## Usage
Run: `/open-prd`

## Steps
1. Read `docs/PRD.md`.
2. Summarize relevant goals, audience, and requirements for the current task.
3. Identify any constraints that affect the requested change.

## Expected Outcome
You have a concise summary of the PRD sections relevant to the task.
