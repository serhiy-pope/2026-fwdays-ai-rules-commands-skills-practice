# dev

## Description
Start the Slidev development server for live editing and preview.

## Usage
Run: `/dev`

## Steps
1. Verify `package.json` includes the `dev` script.
2. If dependencies are not installed, run `npm install`.
3. Run `npm run dev`.
4. Confirm the dev server launches and note the URL.

## Expected Outcome
Slidev dev server is running and the slides are available in the browser.
